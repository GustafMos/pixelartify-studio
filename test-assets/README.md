# Test assets

These files are **procedurally generated** for QA and documentation; no third-party photography is included.

- `scene-640x360.png`, `scene-1920x1080.png` — generated by `scripts/make-test-images.mjs`. The scene contains a bright sky/landscape and a centered subject, useful for testing saliency masks, layer separation and resolution independence.
- `testsrc.mp4` — generated with ffmpeg's `testsrc2` filter at 320×180, 12 fps, 2 seconds. Useful for video import/export tests.

Regenerate:

```bash
node scripts/make-test-images.mjs

# ffmpeg from @ffmpeg-installer/ffmpeg (or a system ffmpeg)
node -e "console.log(require('@ffmpeg-installer/ffmpeg').path)"
ffmpeg -y -f lavfi -i "testsrc2=size=320x180:rate=12" -t 2 \
  -c:v libx264 -pix_fmt yuv420p test-assets/testsrc.mp4
```

The 1920×1080 scene is the same drawing at 3× resolution, so you can compare a 480p and a 1080p input with the same preset and verify that the art size and texture scale match.
