# Credits & references

PixelArtify Studio is an original MIT-licensed implementation. It was inspired by, and references algorithms and data from, the following projects and papers. No source code from the projects below is copied into this repository; where an implementation is derived from an algorithm, the algorithm is cited here and in the source header.

## Core inspiration

### pixel-mosaic — Yogthos

- Repository: <https://github.com/yogthos/pixel-mosaic>
- License: MIT
- Used for: the idea of edge-aware pixelation that aligns sampling windows with image edges, Sobel + non-maximum suppression edge maps, percentile thresholding, and edge-aware colour blending. PixelArtify's sampler, canonical working resolution, offset-field smoothing and layer pipeline are independently implemented and extended.

### Ditherista / libdither — Robert Kist

- Ditherista: <https://github.com/robertkist/ditherista> (MIT)
- libdither: <https://github.com/robertkist/libdither> (BSD-style; includes kdtree and uthash notices)
- Used for: the breadth and naming of the dither/quantization method catalog, palette import/export workflows and UI inspiration. All dithering code in PixelArtify Studio is original TypeScript. The catalog includes standard algorithms from the papers listed below.

### Mediabunny — Vanilagy

- Site: <https://mediabunny.dev>
- Repository: <https://github.com/Vanilagy/mediabunny>
- License: MPL-2.0
- Used as an unmodified dependency for MP4/WebM demuxing, WebCodecs video decoding and muxing/encoding. See `THIRD_PARTY_NOTICES.md`.

## Colour science

- **OKLab** — Björn Ottosson, “A perceptual color space for image processing”, MIT. <https://bottosson.github.io/posts/oklab/>
- **WCAG 2.1 contrast ratio** — W3C. <https://www.w3.org/TR/WCAG21/#contrast-minimum>
- **Machado et al. (2009)** colour-vision-deficiency simulation matrices.
- **HSL / sRGB / linear RGB** conversions follow the standard IEC 61966-2-1 definitions.

## Image processing

- **Kuwahara et al. (1976)** — “Processing of RI-angiocardiographic images”; edge-preserving Kuwahara filter.
- **Haeberli (1990)** — “Paint by Numbers: Abstract Image Representations”; histogram oil-paint filter.
- **Perlin (1985)** and **Musgrave** — fractal value noise used for displacement and texture.
- **Sobel** edge operator; **Canny-style non-maximum suppression** and percentile thresholding.
- **Gortler et al. (1996)** — push–pull pyramid reconstruction, the basis for the inpainting initialization.
- **Telea (2004)** and **Bertalmio et al. (2000)** — directional and diffusion inpainting inspiration.

## Dithering

- **Bayer (1973)** — ordered dithering matrices.
- **Floyd & Steinberg (1976)** — error diffusion.
- **Jarvis, Judice & Ninke (1976)** — three-row error diffusion.
- **Stucki (1981)** — error diffusion.
- **Burkes (1988)** — two-row error diffusion.
- **Sierra (1989)** — Sierra, Two-row Sierra and Sierra Lite kernels.
- **Bill Atkinson / Apple** — Atkinson dithering.
- **Shiau & Fan (1997)** — Shiau–Fan kernel.
- **Ulichney (1993)** — “The void-and-cluster method for dither array generation”; the 64×64 blue-noise matrix is generated by `scripts/generate-blue-noise.mjs`.
- **Riemersma (1998)** — “An optimum dispersed-dot dither matrix”; Hilbert-curve error diffusion.
- **Joel Yliluoma (2009)** — “Arbitrary-palette positional dithering”; the palette-blend mode is a simplified original implementation inspired by the article. <https://bisqwit.iki.fi/story/howto/dither/jy/>
